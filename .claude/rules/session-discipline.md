# Session Discipline

- Capture insights as they surface. Update files at natural breaks, not only at the end.
- Before a session ends: append to `memory/session_log.md` (what happened, what you got wrong, what's next), update the active-work section of `memory/MEMORY.md`, and route any decisions or corrections to their files.
- If the user says "remember this," do it immediately.
- Keep files lean. Summarize older entries instead of letting them sprawl.
